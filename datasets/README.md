# 数据接口

请把真实数据放在各场景目录。原始文件可放入 `raw/`，程序读取每个场景的 `data.npz`。

必需键：`X_train, y_train, X_val, y_val, X_test, y_test`。特征形状为 `[样本, 时间, 通道]` 或 `[样本, 特征]`，标签为 `[样本]`。标签必须明确来自真实标注，分类标签为整数。可增加 `groups_train, groups_val, groups_test`，程序检查三个集合的物理试件ID不重叠。同一轴承的寿命轨迹、同一加工试件切出的时间窗应在同一个集合中。

|目录|原文数据|任务|
|---|---|---|
|D1|CNC turning，Kaggle，doi:10.34740/kaggle/ds/2205074|刀具磨损回归|
|D2-a|ACF-50，原文引用Zenodo doi:10.5281/zenodo.7643683|粗糙度Ra回归|
|D2-b|D2-a频率伸缩，尺寸+10%|粗糙度回归|
|D2-c|D2-a频率伸缩，尺寸−10%|粗糙度回归|
|D3|Paderborn Kat-DataCenter|健康状态分类|
|D4|IEEE PHM 2012|剩余使用寿命回归|
|Dr|工厂提供150个轴承生产振动信号|是否存在故障分类|

原文没有给出文件名、通道顺序、标签单位、样本窗长、数据划分或滤波频带。不能仅将任意文件放入目录就声称完成复现。请依据数据说明书确定这些内容，并将变更写入配置和数据说明。

`convert`支持CSV、MAT与NPZ。CSV使用显式列名；MAT/NPZ在映射文件中使用`x_key,y_key`，可指定`axis_order`调整到样本×时间×通道。请先按物理试件划分，程序不自动随机拆分窗口。参考`configs/data_mapping.example.json`。

D2-b/c生成方案使用周期延拓插值与`1/size_ratio`时间轴缩放，标签保持不变，这是原文缺失细节的重建假设，并不证明变换后的标签仍物理正确。幅值比例默认1，论文未给出不同载荷的数值；需要时修改`amplitude_ratio`。原始D2-a不覆盖。

Dr不上传GitHub，演示数据也不会写入这些真实数据目录。
